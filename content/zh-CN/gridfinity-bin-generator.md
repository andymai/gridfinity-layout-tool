# Gridfinity 收纳盒生成器

一个在你浏览器中运行的参数化收纳盒生成器。设置你的尺寸，添加隔间或挖槽，查看 3D 预览，然后下载一份 STL、STEP 或 3MF 文件。无需安装。它是 [Gridfinity 生成器](/zh-CN/gridfinity-generator)套件的一部分，该套件还包括底板生成器和布局规划器。

[CTA: 开始制作收纳盒](/designer)

## 工作原理

1. **设置你的尺寸。**以网格单位挑选宽度、深度和高度。需要介于标准尺寸之间的？半网格模式给你 0.5 单位精度。
2. **添加你需要的。**隔间、壁挖槽、取物斜面、标签片 — 把它们打开，用滑块调整。
3. **查看预览。**你更改设置时 3D 视图立即更新。旋转和缩放，看清每个角度。
4. **下载并打印。**导出为 STL 供你的切片软件使用，STEP 用于在 CAD 中编辑，或 3MF 用于颜色和材料支持。

> 所有处理都在本地进行。除非你分享，否则你的设计留在你的设备上。

## 功能

**隔间。**把一个收纳盒划分成一片区块网格，最多 8×8。隔板墙会自动生成。如果你想在不重打的情况下重新配置，可以把可拆卸隔板导出为单独的文件。

**取物斜面和壁挖槽。**取物斜面让你更容易够到底部的小零件。壁挖槽 — 任意侧面上的 U 形缺口 — 让你把东西侧向抽出。

**标签片。**后壁上的一个搁架用来放标签条。选择支架式或实心支撑，并为每一列设置宽度。

对于需要固定不动的物品，**底部凹槽**在底面切出成形的凹腔 — 圆形放电池、六边形放批头、矩形放元件。设置深度和旋转以匹配你要收纳的东西。

**挖槽编辑器**处理不寻常的形状。切换到实心模式，从顶部挖出，并用钢笔工具为扳手、钳子或任何轮廓古怪的物品绘制自由路径。

## 底座连接选项

选择收纳盒如何连接到你的底板：

- **标准** — 默认的 Gridfinity 卡槽
- **磁铁** — 为 6mm×2mm 磁铁嵌入的凹腔
- **螺丝** — 用于螺纹嵌件的孔
- **磁铁与螺丝** — 两种方法都用，实现最大固定力
- **加重** — 更重的底座，不用磁铁
- **平底** — 无卡槽，可在没有底板的情况下使用

## 导出格式

| 格式     | 何时使用                                                                    |
| -------- | --------------------------------------------------------------------------- |
| **STL**  | 直接送进你的切片软件。适用于 PrusaSlicer、Cura、OrcaSlicer 及其他所有软件。 |
| **STEP** | 在 Fusion 360、FreeCAD 或 SolidWorks 中打开，以便打印前进一步编辑。         |
| **3MF**  | 包含颜色和材料元数据。适合多材料打印机。                                    |

## 为什么用这个而不是 OpenSCAD？

OpenSCAD 的 gridfinity 生成器能用，但你需要安装软件并编辑代码来更改一个参数。这个在你的浏览器里运行，带可视化界面。你会立即看到结果，而不用等待渲染。

它还能导出 STEP 和 3MF — 不只是 STL — 并且能在你的手机上运行，方便你在外面临时查看点东西。
