# Gridfinity 尺寸与规格

**标准 Gridfinity 尺寸：一个网格单位是 42mm × 42mm（宽度和深度），一个高度单位（1U）是 7mm。**每个收纳盒和底板都是这两个数字的倍数 — 一个 6U 高的 2×3 收纳盒尺寸为 84mm × 126mm × 42mm。半网格模式增加 0.5 单位（21mm）步进。只要你知道这两个数字，就能算出抽屉里放得下什么、该打印哪些收纳盒。

## 网格单位（宽度与深度）

**1 个网格单位 = 42mm。**每个 Gridfinity 收纳盒和底板都用它。一个「2×3」收纳盒宽 2 个单位（84mm）、深 3 个单位（126mm）。

| 网格尺寸 | 毫米  | 英寸（约） |
| -------- | ----- | ---------- |
| 1 个单位 | 42mm  | 1.65″      |
| 2 个单位 | 84mm  | 3.31″      |
| 3 个单位 | 126mm | 4.96″      |
| 4 个单位 | 168mm | 6.61″      |
| 5 个单位 | 210mm | 8.27″      |
| 6 个单位 | 252mm | 9.92″      |
| 7 个单位 | 294mm | 11.57″     |
| 8 个单位 | 336mm | 13.23″     |

### 半网格模式

为了更紧凑的贴合，半网格模式使用 **0.5 单位步进（21mm）**。一个 1.5×2.5 收纳盒会是 63mm × 105mm。在布局工具中按 `H` 启用它。

## 为什么 Gridfinity 是 42mm？

42mm 网格是那个让每个 Gridfinity 收纳盒和底板都能互换的唯一标准。Zack Freedman 在 2022 年设计 Gridfinity 时选了 42mm，因为它正好命中一个甜蜜点：小到足以让一个 1×1 收纳盒装下单个螺丝或 SD 卡而不浪费空间，又大到足以让收纳盒打印得快、结构又结实。

42mm 还能整齐地约分进常见的抽屉和打印床尺寸，并为壁厚、公差间隙以及互锁底座轮廓留出余地 — 正是这个轮廓，让收纳盒既能轻松取出，又能在你拉开抽屉时抵抗滑动。因为这个数字是固定的，你今天打印的收纳盒能配上别人多年前设计的底板 — 这种通用兼容性正是这套标准的全部意义所在。

**标准 Gridfinity 尺寸是一个 42mm × 42mm 的网格单位，高度以 7mm 为步进计量。**其他一切都是这两个数字的倍数。

## 高度单位

**1 个高度单位（1U）= 7mm。**这是你在收纳盒内部获得的垂直空间。一个 3U 收纳盒能装下高约 21mm 的物品。

| 高度 | 内部（mm） | 典型用途                 |
| ---- | ---------- | ------------------------ |
| 2U   | 14mm       | SD 卡、小螺丝、回形针    |
| 3U   | 21mm       | U 盘、AA 电池、螺栓      |
| 4U   | 28mm       | 笔、马克笔、钻头         |
| 5U   | 35mm       | 剪刀、胶带卷、小工具     |
| 6U   | 42mm       | 螺丝刀、钳子（标准深度） |
| 7U   | 49mm       | 喷罐、较大的手工具       |
| 8U   | 56mm       | 胶水瓶、高容器           |
| 10U  | 70mm       | 深度收纳、笨重物品       |

> **净空检查：**你最高的收纳盒加上底板（约 5mm）必须在抽屉关闭时放得下。在决定使用高收纳盒之前，先测量你关闭抽屉的内部高度。

## 如何换算你的抽屉测量值

拿一把卷尺，以毫米为单位量出抽屉的内部尺寸。然后：

1. 以毫米为单位测量内部宽度和深度
2. 各自除以 42
3. 向下取整到最接近的整数（若使用半网格模式则取到半数）

### 示例

```text
抽屉宽度：380mm ÷ 42 = 9.04 → 9 个单位
抽屉深度：520mm ÷ 42 = 12.38 → 12 个单位
布局尺寸：9 × 12（378mm × 504mm）
边缘缝隙：宽 2mm，深 16mm
```

边缘的小缝隙是正常的。底板不需要填满每一毫米。大多数人会把底板居中，忽略缝隙。

## 它能放上你的打印床吗？

大多数 FDM 打印机有 220–256mm 的床面，能处理最多约 5×5 或 6×6 个单位的收纳盒。更大的就需要拆分或分段打印。布局工具默认使用 256mm 打印床，并会标出放不下的收纳盒。
