# Gridfinity 底板生成器

一个在你浏览器中运行的参数化底板生成器。设置你的网格尺寸，配置磁铁孔和边缘填充，查看 3D 预览，然后下载一份 STL、STEP 或 3MF 文件。无需安装。它是 [Gridfinity 生成器](/zh-CN/gridfinity-generator)套件的一部分，该套件还包括收纳盒生成器和布局规划器。

[CTA: 开始生成](/baseplate?standalone=1)

## 工作原理

1. **设置你的尺寸。**以网格单位挑选宽度和深度，或与你现有的布局同步以自动匹配抽屉。
2. **配置功能。**启用磁铁孔以实现磁性固定，添加连接凸点以进行半单元对齐，并逐边设置边缘填充。
3. **查看预览。**你更改设置时 3D 视图立即更新。旋转和缩放，看清每个角度。
4. **下载并打印。**导出为 STL 供你的切片软件使用，STEP 用于在 CAD 中编辑，或 3MF 用于颜色和材料支持。大型底板会自动拆分。

> 所有处理都在本地进行。除非你分享，否则你的设计留在你的设备上。

## 功能

**网格定尺寸。**把底板设为任意宽度和深度，采用标准 Gridfinity 网格单位（每个 42mm）。与你的布局同步以自动匹配抽屉尺寸。

**磁铁孔。**在每个网格交叉点添加 6mm × 2mm 的凹腔，用于标准钕磁铁。收纳盒牢牢吸附在底板上，不会滑动。

**连接凸点。**网格交叉点上的半单元销钉帮助精确对齐收纳盒，配合半网格模式实现 0.5 单位精度时尤其有用。

**边缘填充。**独立配置每一侧的填充 — 左、右、前、后。微调贴合度，让底板在你的抽屉里平齐就位，没有缝隙或干涉。

**自动拆分。**大于你打印床的底板会自动拆分成可打印的部件。下载一个 ZIP，里面包含所有部件，随时可打印和组装。

## 导出格式

| 格式     | 何时使用                                                                    |
| -------- | --------------------------------------------------------------------------- |
| **STL**  | 直接送进你的切片软件。适用于 PrusaSlicer、Cura、OrcaSlicer 及其他所有软件。 |
| **STEP** | 在 Fusion 360、FreeCAD 或 SolidWorks 中打开，以便打印前进一步编辑。         |
| **3MF**  | 包含颜色和材料元数据。适合多材料打印机。                                    |
