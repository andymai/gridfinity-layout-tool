# 如何规划 Gridfinity 抽屉布局

没有方案就打印会浪费耗材。你会因为尺寸猜错而重打收纳盒，留下不想要的缝隙，或者忘了自己到底需要什么。这份指南讲的是如何在动手前测量、规划并得到一份打印清单。

## 测量你的抽屉

拿到以毫米为单位的内部尺寸。你需要：

- **宽度** - 左到右
- **深度** - 前到后
- **高度** - 底到顶（抽屉关闭时的净空）

在几个位置分别测量。抽屉很少是标准矩形，老家具尤其如此。为保险起见，取最小的测量值。

### 换算成网格单位

Gridfinity 使用 42mm 单位。相除并向下取整：

```text
宽度：380mm ÷ 42 = 9.04 → 9 个单位
深度：260mm ÷ 42 = 6.19 → 6 个单位
```

9×6 网格是 378mm × 252mm。边缘会有一些小缝隙。这没关系。底板不需要填满每一毫米。

## 想清楚里面要放什么

大多数人跳过这一步，然后后悔。

把抽屉里的东西全部拿出来。分组：

- 每天用的
- 每周用的
- 你都忘了自己有的

每天用的东西得触手可及。每周用的可以放在后面。忘了的那些也许根本不需要收纳盒。

### 把物品匹配到收纳盒尺寸

粗略参考：

| 物品            | 收纳盒尺寸 |
| --------------- | ---------- |
| M3 螺丝、小元件 | 1×1 带隔板 |
| 笔、U 盘、电池  | 1×2 或 2×2 |
| 螺丝刀、钳子    | 1×3 或 1×4 |
| 胶带、胶水瓶    | 2×2 或 2×3 |
| 大型工具        | 3×3 或更大 |

不用太纠结这个。之后随时可以再打印不同的收纳盒。

## 规划布局

打开工具，设置好网格尺寸。拖动即可创建收纳盒。工具不会让你重叠或超出边界。

**常用物品放在靠前的位置。**打开抽屉时，你最先伸手去拿什么？那就放前面。

**把相关物品归组。**螺丝刀放一处，量具放另一处。你会更容易记住东西在哪。

**留一些空位。**你的收藏会增加。一个今天规划到 100% 满的抽屉，明天就是个麻烦。

### 深抽屉用分层

如果抽屉有高度净空，你可以把收纳盒垂直堆叠。第 1 层是最底层。

这非常适合：

- 扁平物件放底层（线缆、小零件），较高的收纳盒放上层
- 把电气类和机械类分开

重物放底层，常用物放顶层。

## 导出你的打印清单

对布局满意后，导出一份打印清单：

- 每种收纳盒尺寸和数量
- 以克为单位的耗材估算
- 每种尺寸的搜索链接

### 寻找 STL 文件

你可以用内置的收纳盒生成器直接[生成自定义收纳盒](/zh-CN/gridfinity-bin-generator) — 选择你的尺寸、底座样式、隔间，然后导出为 STL、STEP 或 3MF。

对于特殊收纳盒（工具专用的托架、复杂形状），去社区资源库搜索：

- [Printables](https://www.printables.com/search/models?q=gridfinity) - 选择最多
- [Thangs](https://thangs.com/search/gridfinity) - 适合查找相似设计
- [MakerWorld](https://makerworld.com/en/search/models?keyword=gridfinity) - Bambu Lab 社区

示例搜索：「gridfinity 2x2 3U」可找到高 3 个高度单位的 2×2 收纳盒。

## 打印之前

### 先用纸板测试

> 按你的收纳盒尺寸（每个网格单位 42mm）裁好纸板，摆进抽屉里。如果哪里感觉不对，你还没浪费任何耗材。

### 先打印一个收纳盒

在打印 20 个之前，先打印一个。检查贴合度、检查高度，确认你喜欢这个设计。需要的话调整打印机设置。

### 检查你的净空

你最高的收纳盒加上底板（约 5mm）必须在抽屉关闭时放得下。在决定使用高收纳盒之前先测量这一点。

## 常见错误

**太多小收纳盒。**一整片 1×1 收纳盒看着很整齐，但用起来很烦。带隔板的大收纳盒通常更好。

**填满每一格。**这样就没有空间放新东西了。规划时留出 10-20% 的空位。

**忽略你实际会用的东西。**别按你以为自己该有的东西来整理，按你真正会伸手去拿的东西来整理。
