# Gridfinity 사이즈와 치수

**표준 Gridfinity 크기: 그리드 한 단위는 42mm × 42mm(너비와 깊이)이고, 높이 한 단위(1U)는 7mm예요.** 모든 수납통과 베이스플레이트는 이 두 숫자의 배수예요 — 6U 높이의 2×3 수납통은 84mm × 126mm × 42mm고요. 하프 그리드 모드는 0.5단위(21mm) 증분을 더해줘요. 이 두 숫자만 알면 서랍에 무엇이 들어갈지, 어떤 수납통을 프린트할지 계산할 수 있어요.

## 그리드 단위 (너비 & 깊이)

**1 그리드 단위 = 42mm.** 모든 Gridfinity 수납통과 베이스플레이트가 이걸 써요. "2×3" 수납통은 너비 2단위(84mm), 깊이 3단위(126mm)예요.

| 그리드 크기 | 밀리미터 | 인치 (근사) |
| ----------- | -------- | ----------- |
| 1단위       | 42mm     | 1.65″       |
| 2단위       | 84mm     | 3.31″       |
| 3단위       | 126mm    | 4.96″       |
| 4단위       | 168mm    | 6.61″       |
| 5단위       | 210mm    | 8.27″       |
| 6단위       | 252mm    | 9.92″       |
| 7단위       | 294mm    | 11.57″      |
| 8단위       | 336mm    | 13.23″      |

### 하프 그리드 모드

더 빡빡한 맞음새를 위해 하프 그리드 모드는 **0.5단위 증분(21mm)**을 써요. 1.5×2.5 수납통은 63mm × 105mm가 돼요. 레이아웃 도구에서 `H`를 눌러 켜세요.

## Gridfinity는 왜 42mm인가요?

42mm 그리드는 모든 Gridfinity 수납통과 베이스플레이트를 서로 호환되게 만드는 단 하나의 표준이에요. Zack Freedman은 2022년에 Gridfinity를 설계하면서 42mm를 골랐는데, 절묘한 지점을 짚었기 때문이에요. 1×1 수납통이 낱개 나사나 SD 카드를 공간 낭비 없이 담을 만큼 작으면서도, 수납통이 빠르게 프린트되고 튼튼하게 유지될 만큼 커요.

42mm는 흔한 서랍과 프린트 베드 크기로 깔끔하게 나눠지기도 하고, 벽 두께와 공차 간격, 그리고 맞물리는 밑면 윤곽을 위한 여유도 남겨요 — 바로 이 윤곽 덕분에 수납통이 쉽게 들어올려지면서도 서랍을 열 때 미끄러지지 않고 버텨요. 숫자가 고정되어 있으니, 오늘 프린트한 수납통이 누군가 몇 년 전에 설계한 베이스플레이트에 맞아요 — 이 보편적 호환성이 바로 이 표준의 존재 이유예요.

**표준 Gridfinity 크기는 42mm × 42mm의 그리드 한 단위이고, 높이는 7mm 증분으로 측정해요.** 나머지는 전부 이 두 숫자의 배수예요.

## 높이 단위

**높이 한 단위(1U) = 7mm.** 이게 수납통 내부에서 얻는 수직 공간이에요. 3U 수납통은 높이 약 21mm까지의 물건을 담아요.

| 높이 | 내부 (mm) | 대표 용도                      |
| ---- | --------- | ------------------------------ |
| 2U   | 14mm      | SD 카드, 작은 나사, 클립       |
| 3U   | 21mm      | USB 드라이브, AA 배터리, 볼트  |
| 4U   | 28mm      | 펜, 마커, 드릴 비트            |
| 5U   | 35mm      | 가위, 테이프 롤, 작은 공구     |
| 6U   | 42mm      | 드라이버, 플라이어 (표준 깊이) |
| 7U   | 49mm      | 스프레이 캔, 큰 수공구         |
| 8U   | 56mm      | 접착제 병, 높은 용기           |
| 10U  | 70mm      | 깊은 수납, 부피 큰 물건        |

> **여유 확인:** 가장 높은 수납통에 베이스플레이트(약 5mm)를 더한 값이 서랍을 닫았을 때 들어가야 해요. 높은 수납통을 결정하기 전에 닫은 서랍의 내부 높이를 측정하세요.

## 서랍 치수를 환산하는 법

줄자를 들고 서랍의 내부 치수를 밀리미터로 재세요. 그다음:

1. 내부 너비와 깊이를 밀리미터로 측정
2. 각각 42로 나누기
3. 가장 가까운 정수로 내림(하프 그리드 모드라면 0.5 단위로 내림)

### 예시

```text
서랍 너비:  380mm ÷ 42 = 9.04 → 9단위
서랍 깊이:  520mm ÷ 42 = 12.38 → 12단위
레이아웃 크기:   9 × 12 (378mm × 504mm)
가장자리 틈:  너비 2mm, 깊이 16mm
```

가장자리의 작은 틈은 정상이에요. 베이스플레이트가 매 밀리미터를 다 채울 필요는 없어요. 대부분 베이스플레이트를 가운데에 놓고 틈은 무시해요.

## 흔한 수납통 크기

대부분 프린트하는 것들이에요. 이 중 어떤 것이든(또는 어떤 맞춤 크기든) [수납통 생성기](/ko/gridfinity-bin-generator)에서 만들 수 있어요.

| 수납통 크기 | 치수 (mm) | 흔한 용도                           |
| ----------- | --------- | ----------------------------------- |
| 1×1         | 42 × 42   | 낱개 나사, 너트, 작은 부품          |
| 1×2         | 42 × 84   | 펜, USB 케이블, 한 줄로 놓은 배터리 |
| 1×3         | 42 × 126  | 드라이버, 자, 긴 공구               |
| 2×2         | 84 × 84   | 테이프, 글루 스틱, 줄자             |
| 2×3         | 84 × 126  | 플라이어, 와이어 커터, 중간 공구    |
| 3×3         | 126 × 126 | 드릴 비트 세트, 큰 액세서리         |
| 4×2         | 168 × 84  | 소켓 렌치, 캘리퍼 수납              |

## 프린트 베드에 들어갈까요?

대부분의 FDM 프린터는 220~256mm 베드를 갖고 있어서, 약 5×5나 6×6 단위까지의 수납통을 다뤄요. 그보다 크면 분할하거나 나눠서 프린트해야 해요. 레이아웃 도구는 기본값으로 256mm 프린트 베드를 쓰고, 들어가지 않는 수납통을 표시해줘요.
