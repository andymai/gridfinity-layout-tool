# Gridfinity 서랍 레이아웃 계획하는 법

계획 없이 프린트하면 필라멘트를 낭비해요. 크기를 잘못 짐작해 수납통을 다시 프린트하거나, 원치 않던 틈을 남기거나, 무엇이 필요했는지 잊게 되죠. 이 가이드는 시작하기 전에 어떻게 측정하고, 계획하고, 프린트 목록을 얻는지 다뤄요.

## 서랍 측정하기

내부 치수를 밀리미터로 구하세요. 필요한 건 이거예요.

- **너비** - 좌우
- **깊이** - 앞뒤
- **높이** - 바닥에서 위까지(닫았을 때의 여유 공간)

몇 군데에서 측정하세요. 서랍은 완벽한 직사각형인 경우가 드물고, 오래된 가구는 특히 그래요. 안전하게 가장 작은 측정값을 쓰세요.

### 그리드 단위로 환산하기

Gridfinity는 42mm 단위를 써요. 나눈 뒤 내림하세요.

```text
너비:  380mm ÷ 42 = 9.04 → 9단위
깊이:  260mm ÷ 42 = 6.19 → 6단위
```

9×6 그리드는 378mm × 252mm예요. 가장자리에 작은 틈이 생겨요. 괜찮아요. 베이스플레이트가 매 밀리미터를 다 채울 필요는 없어요.

## 무엇을 넣을지 정하기

대부분 이 단계를 건너뛰고 후회해요.

서랍에 든 걸 전부 꺼내세요. 그리고 묶어보세요.

- 매일 쓰는 물건
- 매주 쓰는 물건
- 가지고 있는지도 잊었던 물건

매일 쓰는 물건은 손이 잘 닿아야 해요. 매주 쓰는 건 뒤쪽에 둬도 돼요. 잊었던 물건은 아예 수납통이 필요 없을 수도 있고요.

### 물건을 수납통 크기에 맞추기

대략적인 기준이에요.

| 물건                     | 수납통 크기      |
| ------------------------ | ---------------- |
| M3 나사, 작은 부품       | 1×1에 칸막이     |
| 펜, USB 드라이브, 배터리 | 1×2 또는 2×2     |
| 드라이버, 플라이어       | 1×3 또는 1×4     |
| 테이프, 접착제 병        | 2×2 또는 2×3     |
| 큰 공구                  | 3×3 또는 그 이상 |

너무 집착하지 마세요. 나중에 언제든 다른 수납통을 프린트하면 돼요.

## 레이아웃 계획하기

도구를 열고 그리드 크기를 설정하세요. 드래그하면 수납통이 만들어져요. 도구는 겹치거나 경계를 벗어나게 두지 않아요.

**자주 쓰는 물건을 앞쪽에 두세요.** 서랍을 열었을 때 가장 먼저 손이 가는 건 무엇인가요? 그게 앞에 와야 해요.

**관련된 물건을 묶으세요.** 드라이버는 한 곳에, 측정 공구는 다른 곳에. 물건이 어디 있는지 더 잘 기억나요.

**빈 공간을 좀 남기세요.** 컬렉션은 늘어나요. 오늘 100% 계획해 꽉 찬 서랍은 내일 골칫거리예요.

### 높은 서랍에는 레이어 활용하기

서랍에 높이 여유가 있다면 수납통을 세로로 쌓을 수 있어요. 레이어 1이 맨 아래예요.

이런 경우에 잘 맞아요.

- 납작한 물건(케이블, 작은 부품)은 아래, 더 높은 수납통은 위
- 전기 부품과 기계 부품을 분리

무거운 건 아래에, 자주 쓰는 건 위에 두세요.

## 프린트 목록 내보내기

레이아웃이 마음에 들면 프린트 목록을 내보내세요.

- 모든 수납통 크기와 수량
- 그램 단위 필라멘트 추정치
- 각 크기의 검색 링크

### STL 파일 찾기

내장 수납통 생성기로 [맞춤 수납통을 바로 생성](/ko/gridfinity-bin-generator)할 수 있어요 — 치수, 밑면 스타일, 칸을 고르고 STL, STEP, 3MF로 내보내세요.

특수한 수납통(공구 전용 홀더, 복잡한 형상)은 커뮤니티 저장소에서 검색하세요.

- [Printables](https://www.printables.com/search/models?q=gridfinity) - 선택지가 가장 많아요
- [Thangs](https://thangs.com/search/gridfinity) - 비슷한 디자인 찾기에 좋아요
- [MakerWorld](https://makerworld.com/en/search/models?keyword=gridfinity) - Bambu Lab 커뮤니티

검색 예시: "gridfinity 2x2 3U"는 높이가 3단위인 2×2 수납통을 찾아줘요.

## 프린트하기 전에

### 먼저 종이상자로 테스트하기

> 수납통 크기(그리드 단위당 42mm)에 맞게 종이상자를 잘라 서랍에 배치해 보세요. 뭔가 어색하다면, 필라멘트는 아직 하나도 낭비하지 않은 거예요.

### 수납통 하나를 먼저 프린트하기

20개를 프린트하기 전에 하나를 먼저 프린트하세요. 맞음새와 높이를 확인하고, 디자인이 마음에 드는지 보세요. 필요하면 프린터 설정을 조정하세요.

### 여유 공간 확인하기

가장 높은 수납통에 베이스플레이트(약 5mm)를 더한 값이 서랍을 닫을 때 들어가야 해요. 높은 수납통을 결정하기 전에 이걸 측정하세요.

## 흔한 실수

**너무 많은 작은 수납통.** 1×1 수납통을 격자처럼 늘어놓으면 정돈돼 보이지만 쓰기 번거로워요. 칸막이가 있는 큰 수납통이 대개 더 나아요.

**모든 칸을 채우기.** 새 물건을 넣을 자리가 없어져요. 10～20%의 빈 공간을 계획하세요.

**실제로 쓰는 걸 무시하기.** 가져야 한다고 생각하는 것 기준으로 정리하지 마세요. 실제로 손이 가는 것 기준으로 정리하세요.
