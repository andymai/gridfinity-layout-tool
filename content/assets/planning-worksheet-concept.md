# Gridfinity Planning Worksheet - Design Concept

This document outlines the content and design for a downloadable PDF planning worksheet.

## Purpose
- Lead magnet to capture email addresses (optional)
- Valuable standalone resource that reinforces your brand
- Printable companion to the web-based Layout Tool

## Design Notes

### Color Scheme
- Match GridfinityLayoutTool.com branding
- Dark background option for printing efficiency
- Clear, high-contrast text

### Format
- A4 / Letter size (8.5" × 11")
- PDF format
- Fillable form fields (optional)

### Branding
- Subtle logo placement (header/footer)
- Website URL on each page
- QR code linking to the tool (optional)

### Distribution Options
1. **Direct download**: No email required (best for SEO/sharing)
2. **Email gate**: Require email to build list (reduces downloads)
3. **Hybrid**: Offer both (ungated summary + gated full version)
